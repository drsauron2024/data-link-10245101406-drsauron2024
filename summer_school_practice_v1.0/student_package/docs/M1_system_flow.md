# M1 系统处理流程图与说明

## 全链路处理流程

```
┌─ 发送方域 ────────────────────┐   ┌─ 链路 ─┐   ┌─ 接收方域 ──────────────────────────────────┐
│ OpenSky离线数据                │   │        │   │                                             │
│  (raw_states.json 教学样例)    │   │ 41字节 │   │  解封与校验 ──▶ CSV/SQLite(选做)            │
│  (opensky_real/ 真实快照)      │   │ 帧     │   │   ──▶ 航迹与当前态势                       │
│      │                        │   │        │   │       ──▶ 语义映射(候选→核验→正式)         │
│      ▼                        │   │        │   │           ──▶ 一致性检查(R1-R4)           │
│  发送方解析与内部状态           │   │        │   │               ──▶ 态势结果与告警          │
│  (索引映射/必需可空校验/        │   │        │   │                                             │
│   时间与高度回退/量程检查)      │   │        │   │  校验失败 ──▶ validation_log 记错误不崩溃  │
│      │                        │   │        │   │                                             │
│      ▼                        │   │        │   │                                             │
│  教学消息封装                  │──▶│────────▶│                                             │
│  (Q量化/标志位/校验和/41字节)   │   │        │   │                                             │
└───────────────────────────────┘   └────────┘   └─────────────────────────────────────────────┘
```

## 各环节输入与输出

| 环节 | 输入 | 输出 |
|---|---|---|
| 发送方解析 | OpenSky 状态向量数组 | 发送方内部记录（标准命名 dict） |
| 消息封装 | 发送方内部记录 + 序号 | 41 字节 TeachingLink 帧（encoded_messages.bin） |
| 模拟传输 | 帧流 | 帧流（单向一次投递，无重传） |
| 接收方解封校验 | 帧流 | 接收方记录（message_valid + validation_errors） |
| 存储 | 接收方记录 | CSV（decoded_*.csv）；SQLite（states.db，选做） |
| 航迹与态势 | 多时刻解码记录 | track_table.csv / current_situation.csv |
| 语义映射 | 两种来源态势 | unified_situation.ndjson |
| 一致性检查 | 混合记录 + 固定规则 | alert_log.csv / quality_situation.csv |
